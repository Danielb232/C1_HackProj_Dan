    Demonstrate the complete loop

    1. Use real course material. Upload a syllabus and reading, inspect the extracted text, and generate a concept map, review sheet, and quiz.
    2. Check the model’s work. Have a teammate compare answers with the source passages. Record a correction or flag; quote matching is not fact-checking.
    3. Show memory, not just a score. Miss one question, answer another correctly but uncertainly, then close and reopen Echo. Re-quiz only the missed concept; show the separate confidence-practice queue.

    What to explain to the judges

    Inclusive presentation
    Focus offers ADHD-paced chunks. Read uses dyslexia-friendly spacing. Listen provides a linear, keyboard-accessible screen-reader outline. These are presentation options, not clinical or accessibility certifications.
    Local small model
    Qwen 2.5 3B runs through Ollama on this computer. After setup, generation is offline-capable and needs no cloud API tokens. The model can still make factual mistakes.
    Persistent review
    Each study guide keeps its own answers, confidence signals, and review notes in browser storage. Review repeats saved questions; calendar-based spaced repetition is not implemented.
